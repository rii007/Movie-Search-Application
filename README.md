# 🎬 Movie Search Application

A simple movie search application built with **HTML, CSS, and JavaScript**.

## 🚀 Features
- Search for movies by title
- View posters, ratings, and overviews
- Popular movies displayed on page load
- Ratings are color-coded (green, orange, red)

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- TMDb API
